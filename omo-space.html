Omo Space

Chat windows were built for one conversation. Now there are twenty, and they keep running when you look away. So we gave every agent a room.

Find, resume, monitor, orchestrate: our working paper found that a place turns all four into things people already do well. This page is the system behind it: what it is, how it works, what survives what, and what it does not do yet.

Quick start with your agent

Install it and build your first world, in one prompt

Pick what your world should be, or type your own. Paste it into Claude Code, Codex or Hermes, opened in an empty folder.

Needs a Minecraft Java account, Python 3.11+ and about 2 GB free. Tested end to end on Linux; macOS and Windows are newer.







Abstract


People remember rooms better than tabs. Omo Space uses that: it gives every long-running agent a place in a shared 3D world, so finding one becomes walking to it, resuming becomes coming back to where you left it, and checking on the team becomes a glance down the hallway S6. It is a Minecraft mod and a small local service. Placing a computer block starts a named workspace on your own PC: a Hermes Agent conversation, a Claude Code or Codex session, or a plain shell. Its terminal is painted on a wall, real web pages run on monitors beside it, and a lamp shows whether it is working. Walking away, or quitting the game, stops nothing, because the sessions belong to a background session server, not to the game S1S2. This page describes what Omo Space is, how it is built, what survives what, what we built with it this week, and what it does not do yet. Version 1.2.0 was released on 28 October 2026 under the MIT licence S3S8.


01
Introduction


Most agent interfaces disappear when you close the window. The agent is a tab, the tab looks like every other tab, and after a dozen of them it is hard to say which one is which, which one is working and which one is waiting for you.




Omo Space starts from the opposite end. Each agent gets a place: a desk in a room, with its terminal on the wall and its name on a plate. You find it by walking to it. You check on it by looking down the hallway. When you come back the next day, it is where you left it S1.


Our companion paper, Rooms, Not Windows, reports five days of using it as a main workspace S6. This page is the system itself.


02
What you can build


Everything is an ordinary-looking game block. The blocks below are the whole kit S1:








Block
What it does






Hermes Computer
One named workspace with a Hermes conversation in the profile you choose. Different agents, different desks.




Terminal
A persistent shell. Its "+" menu opens Shell, Hermes, Claude Code or Codex tabs.




Omo Monitor / Slim Screen
A bigger view of a terminal, or a real Chromium page: up to 6 tabs, its own sound, WASD for web games.




Omo Linker
Mirrors a station onto walls across the room, with no wiring.




Omo Pocket
A Hermes or Terminal workspace you carry as an item.




Name Plate / Status Lamp
A name, and a live working / idle / interrupted light that also drives redstone.






Claude Code and Codex tabs are on the main branch and ship in the next release S3.


03
How it works


The game is only the view. Four steps describe the whole interaction S1:




in the gameYou at a deskcomputer, pocket or wall
→

127.0.0.1 onlyLocal bridgepaints screens, sends keys
→

background servicetmux sessionsowns every workspace
→

your PCReal agentsHermes, Claude Code, Codex, shell





    

  1. Place a desk. A Hermes Computer or Terminal block opens a named workspace on your PC.
    2. 

  2. Type on the wall. Your keys go to a real shell or agent, and its terminal is painted in the world.
    3. 

  3. Walk away. tmux owns every session. Quit Minecraft and the work goes on while your PC is awake.
    4. 

  4. Come back. It is on the wall where you left it. After a reboot, the desk reopens its tabs; nothing is re-run.
    5. 



Underneath, a small bridge listens on 127.0.0.1 only. It paints the sessions onto in-game screens and sends your keystrokes back. The sessions themselves live in a tmux session server that runs as a background service S1S4.


Web walls are real Chromium pages. Since v1.2.0 a world can show 12 pages at once. A guard rate-limits new pages and closes all but the nearest walls if memory runs high, which fixed a crash where three walls kept evicting each other's page S3.

Two rules hold throughout. State is reported honestly: if the session server stops, the screen says INTERRUPTED. And nothing is re-run on its own: "Commands that were running are never re-run" S2.


05
What we built with it this week


We use Omo Space as our main workspace, live on stream. Between 25 and 29 October 2026 the builder ran a content pipeline from inside the game, with one room per stage: ideas, references, recording requirements, editing, publishing and analytics. Each room has its own Hermes profile S6.
▶ Watch the 15-minute demo














The rooms themselves were built by agents. The main underground base, with one room per stage, "Was done in one shot One prompt" S6. An underground robot lab was also built from one prompt, live on stream S1.


At the time of the companion paper, the bridge on the builder's machine reported 114 known workspaces, 62 live tmux sessions and 22 separate Hermes profiles. At peak he ran 21 to 25 agent sessions at once S6.


Since v1.2.0, agents running on the same computer can also join the world as players, over a LAN port that refuses offline logins from other machines S2S3. Our robots and the OMO agent player are built on that, and are described in Bodies in the Block World S7.


06
Install


Download the installer, your platform's bundle and SHA256SUMS from the v1.2.0 release, check them, then install S1S8:


curl -LO https://github.com/omoresearch/omo-space/releases/download/v1.2.0/install.sh
curl -LO https://github.com/omoresearch/omo-space/releases/download/v1.2.0/omo-research-1.2.0-linux-x64.tar.gz
curl -LO https://github.com/omoresearch/omo-space/releases/download/v1.2.0/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS
bash install.sh omo-research-1.2.0-linux-x64.tar.gz



    

  • The launcher fetches Minecraft 26.2, Fabric, CC: Tweaked, MCEF and Java from their official sources, with pinned hashes, into its own folder. It never touches your Minecraft or Prism installs.
    • 

  • You need your own Minecraft Java account, Python 3.11+ and about 2 GB free. Hermes Agent is optional, and model access is your own.
    • 

  • Setup fetches about 650 MB; the in-game browser fetches about 360 MB the first time a web wall opens.
    • 

  • On Windows 10/11 the game runs natively, and the sessions and Hermes run in WSL2 (install.ps1).
    • 



07
Security model


Omo Space puts real shells on your computer behind blocks in a world, so it should be treated with the same care as a terminal S4:


    

  • The bridge listens on 127.0.0.1 only and refuses foreign Host headers.
    • 

  • A computer's screen only ever holds a single-use ticket, bound to its station, its workspace and the running bridge.
    • 

  • Worlds store workspace ids and monitor URLs, never a credential.
    • 

  • Hermes' own approval prompts and permissions are untouched. Nothing here enables paid inference by itself.
    • 



It is for singleplayer and trusted local worlds. "A block, a room or a pocket dimension is a presentation boundary, not a sandbox." S4


08
Limitations




    

  • Platforms. Tested end to end on Linux. macOS and Windows support is new and tested offline only; a clean-machine install through Microsoft sign-in has not been tested yet S1S5.
    • 

  • Desk agents do not act in the world. "A Hermes desk agent does not act in the world. It cannot walk, place blocks or press buttons." Agent bodies are a separate runtime S2.
    • 

  • Agents do not talk to each other through the world. Work is handed between them the normal Hermes way S2.
    • 

  • Workspaces live on the PC that opened them. A friend on another PC gets a fresh workspace from the same preset S2.
    • 

  • Web video. The bundled Chromium has no H.264/AAC codecs, so YouTube plays but most Instagram, X and Reddit video does not S1.
    • 

  • The game is heavier than the work. In our own use, the game client crashed or froze more often than the agent sessions failed; the sessions survived S6.
    •
